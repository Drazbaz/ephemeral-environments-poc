# Ephemeral Environments PoC

A proof-of-concept ASP.NET Core API demonstrating:

- Dockerised API
- PostgreSQL
- EF Core migrations
- Repository pattern
- Unit of Work
- Test containers

## Running

docker compose up --build

## API

GET /api/user <br>
POST /api/user

## Tech Stack

- .NET
- PostgreSQL
- Docker
- EF Core
